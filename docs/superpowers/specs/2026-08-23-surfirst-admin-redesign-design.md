# 서퍼스트 관리자 UI/UX 전면 개편 설계

날짜: 2026-08-23

## 목적
서퍼스트 사장님이 매일 사용하는 관리자 페이지를 "현장 운영 커맨드센터"로 재설계한다.
목표는 보기 좋은 대시보드가 아니라, 예약·문의·입금·사진 전달을 빠르게 판단하고 처리하는
작업형 SaaS 콘솔이다.

## 범위
개편 대상:
- `/admin/` 홈
- `/availability/admin` 예약 관리
- `/dashboard/` 분석
- `/photos/admin` 사진 전달
- `/admin/login` 로그인

제외 대상:
- `/` 오손 OSON 랜딩페이지
- 카카오톡 웹훅, 예약 API, 사진 업로드 API, Supabase 스키마
- 기능 추가성 백엔드 변경

## 현재 상태 진단
현재 관리자 UI는 FastAPI 라우터 파일 안의 HTML/CSS/JS 문자열로 구성되어 있다.
주요 화면은 기능적으로 동작하지만 다음 문제가 있다.

- 공통 레이아웃, 디자인 토큰, 버튼, 카드, 상태 배지 스타일이 화면마다 중복된다.
- `/admin`, `/availability/admin`, `/photos/admin`, `/dashboard`가 하나의 제품처럼 연결되지 않는다.
- 홈 화면은 문의·수입·최근 대화를 모두 보여주지만, 오늘 운영 판단의 우선순위가 흐릿하다.
- 예약 화면은 기능은 많지만 현장 사용자의 핵심 작업인 날짜 이동, 잔여석 확인, 입금대기 처리,
  예약 추가가 시각적으로 분리되어 있다.
- 분석 화면은 홈의 수입 차트와 역할이 일부 겹친다.
- 이모지 중심 네비게이션과 일반적인 indigo SaaS 색상이 서퍼스트 현장 운영의 정체성을 약하게 만든다.

## 제품 방향
추천 방향은 "현장 운영 커맨드센터"다.

첫 화면은 오늘 영업 상태를 한눈에 보여준다. 예약 관리 화면은 현장 직원이 바로 수정할 수 있는
작업대가 된다. 분석 화면은 운영 중 확인하는 화면이 아니라 장사 흐름을 보는 리포트로 분리한다.
사진 화면은 QR 발급과 업로드 상태를 빠르게 처리하는 전달 도구로 정리한다.

## 디자인 원칙
- **오늘 우선**: 날짜가 있는 정보는 오늘, 내일, 이번 달 순서로 배치한다.
- **작업 우선**: 카드 장식보다 버튼, 상태, 입력, 목록 밀도를 우선한다.
- **모바일 우선**: 현장에서는 휴대폰 사용 가능성이 높으므로 한 손 조작과 가로 스크롤 최소화가 중요하다.
- **데스크톱 확장**: 데스크톱에서는 사이드바와 2열/3열 레이아웃으로 정보 밀도를 높인다.
- **상태 색상 일관성**: 예약 확정, 입금대기, 마감, 노쇼, 위험 상태를 모든 화면에서 같은 색으로 표현한다.
- **오손과 분리**: 오손 랜딩의 코럴 브랜드와 혼동하지 않고, 서퍼스트 운영 콘솔만의 톤을 만든다.

## 시각 시스템
서퍼스트 관리자 콘솔은 한강 수상레저 현장의 물, 장비, 운영 신호에서 가져온 색을 사용한다.
밝고 친근하지만, 장시간 관리 화면으로 보아도 피로하지 않게 저채도 기반으로 설계한다.

색상 토큰:
- `--sf-bg`: `#F4F8FA` 밝은 강물 배경
- `--sf-surface`: `#FFFFFF` 기본 패널
- `--sf-surface-raised`: `#F9FCFD` 보조 패널
- `--sf-ink`: `#17242B` 본문
- `--sf-muted`: `#667780` 보조 텍스트
- `--sf-line`: `#D9E4E8` 경계선
- `--sf-navy`: `#12313F` 상단/사이드 내비게이션
- `--sf-river`: `#0E8FA3` 주요 액션과 오늘 강조
- `--sf-yellow`: `#F4B740` 입금대기와 확인 필요
- `--sf-green`: `#168A5B` 예약 확정과 정상
- `--sf-red`: `#D94A3A` 마감, 삭제, 장애
- `--sf-blue`: `#2F6FDB` 패들보드/정보
- `--sf-purple`: `#7657D6` 카약/보조 구분

어두운 테마는 유지하되, 새 토큰의 dark variant를 공통 CSS에서 정의한다.

타이포그래피:
- 기본: 시스템 한글 폰트 유지 (`-apple-system`, `Apple SD Gothic Neo`, `Malgun Gothic`)로 빠른 로딩과 안정성을 우선한다.
- 숫자: `font-variant-numeric: tabular-nums`를 적용해 예약 인원, 금액, 시간의 흔들림을 줄인다.
- 제목: 큰 마케팅 헤드라인이 아니라 18-24px의 작업형 제목 체계를 사용한다.

형태:
- 반복 카드와 모달은 8-12px radius 중심.
- 페이지 전체를 카드 안에 넣지 않는다.
- 상태 배지는 작은 알약형 대신 읽기 쉬운 compact label로 통일한다.
- 버튼은 텍스트 액션과 아이콘 액션을 분리한다. 삭제, 수정, 새로고침 같은 반복 액션은 동일한 위치와 크기를 쓴다.

## 공통 레이아웃
공통 관리자 shell을 도입한다.

데스크톱:
```text
+----------------+--------------------------------------+
| 서퍼스트        | 오늘 운영 / 예약 / 사진 / 분석      |
| 운영 콘솔       |--------------------------------------|
|                | page title + quick actions            |
| 홈             |--------------------------------------|
| 예약           | main content                          |
| 사진           |                                      |
| 분석           |                                      |
+----------------+--------------------------------------+
```

모바일:
```text
+--------------------------------------+
| 서퍼스트 운영 콘솔      actions       |
| 홈  예약  사진  분석                  |
+--------------------------------------+
| page title / today strip              |
| main content                          |
+--------------------------------------+
```

공통 요소:
- 현재 화면, 오늘 날짜, 새로고침, 테마 전환, 로그아웃을 일관된 위치에 둔다.
- 네비게이션 문구는 `홈`, `예약`, `사진`, `분석`으로 짧게 유지한다.
- 이모지는 제거하거나 최소화하고, 텍스트와 상태 색을 중심으로 구분한다.

## 화면별 설계

### 로그인
로그인 화면은 어두운 navy 배경에 작은 브랜드 패널을 둔다.
목표는 "관리자용 보안 진입점"이지 홍보 화면이 아니다.

구성:
- 서퍼스트 운영 콘솔
- 비밀번호 입력
- 자동 로그인 체크
- 로그인 버튼
- 오류 메시지는 입력창 바로 위에 노출

### 홈 `/admin/`
홈은 오늘의 운영 판단 화면이다.

상단 구성:
- 오늘 날짜와 영업 요약
- 오늘 방문 인원, 오늘 확정 수입, 입금대기, 예약 의향 문의를 4개 핵심 지표로 표시
- 경고가 있는 경우, 예: 입금대기 1건 이상, 미확인 예약문의, 노쇼, 가장 먼저 노출

본문 구성:
- 왼쪽 또는 상단: 오늘 예약 타임라인 요약
- 오른쪽 또는 하단: 예약 의향 고객과 최근 대화
- 수입 분석의 상세 차트는 홈에서 줄이고 `/dashboard/`로 이동

홈의 주 액션:
- 예약 추가
- 입금대기 보기
- 예약문의 보기
- 새로고침

### 예약 `/availability/admin`
예약 관리는 가장 중요한 작업 화면이다.

상단:
- 날짜 선택과 `오늘`, `내일`, `모레`, 이전/다음 버튼
- 날짜 변경 시 잔여석과 예약 목록이 즉시 같은 화면에서 갱신된다.

잔여석:
- 종목/시간대별 잔여석 보드는 상단에 compact grid로 둔다.
- `여유`, `주의`, `마감` 상태를 색과 텍스트로 함께 표시한다.
- 클릭 시 해당 슬롯 예약자 명단을 보여준다.

예약 입력:
- 모바일에서는 접이식 또는 상단 고정 CTA `예약 추가`로 시작한다.
- 데스크톱에서는 우측 패널 또는 상단 inline form으로 유지한다.
- 입력 필드는 현재 기능을 유지한다: 날짜, 종목, 시간, 이름, 인원, 플랫폼, 결제수단, 실수령 금액,
  예약금, 상태, 메모.

예약 목록:
- 시간순 타임라인으로 표시한다.
- 각 행은 시간, 고객명, 종목, 인원, 금액, 상태, 액션을 포함한다.
- 입금대기 행은 노란 상태 표시와 `확정` 빠른 버튼을 제공한다.
- 모바일에서는 금액과 메타정보를 2줄 요약으로 접고, 수정 버튼을 명확히 둔다.

### 사진 `/photos/admin`
사진 화면은 "앨범 만들기 -> QR 보여주기 -> 사진 업로드" 흐름을 빠르게 만든다.

상단:
- 새 앨범 만들기 입력과 버튼
- 설명 문구는 짧게: "앨범을 만들고 QR을 손님에게 보여주세요."

앨범 목록:
- 활성 앨범을 먼저 보여준다.
- 각 앨범은 QR, 코드, 만료 시간, 사진 수, 공개 링크, 업로드 영역, 삭제 액션을 포함한다.
- 업로드 영역은 드래그 앤 드롭과 클릭 선택을 유지하되, 업로드 중/완료/실패 상태를 분명히 표시한다.

손님용 갤러리 `/photos/p/{code}`는 관리자 개편의 부속 화면으로 톤만 가볍게 맞춘다.

### 분석 `/dashboard/`
분석은 영업 리포트 화면으로 분리한다.

상단:
- 오늘, 이번 달, 누적 예약, 노쇼율 지표

탭:
- 개요
- 채널·종목
- 캘린더

개편 포인트:
- 홈과 중복되는 수입 분석 블록은 상세 분석 쪽으로 모은다.
- 차트 카드의 제목과 범례를 더 작고 일관되게 정리한다.
- 표는 매출, 건수, 인원, 비율을 같은 정렬 규칙으로 표시한다.

## 구현 전략
현재 라우터 문자열 구조를 유지한 채 디자인만 수정하면 중복이 계속 커진다.
따라서 첫 구현 단계에서 공통 관리자 자산을 분리한다.

제안 구조:
```text
static/admin/
  surf-admin.css
  surf-admin.js
```

각 라우터 HTML은 다음을 공유한다.
- 공통 CSS 토큰과 shell 스타일
- 테마 토글
- 공통 포맷 유틸리티 일부
- 접근성 focus style

단, 대규모 템플릿 엔진 도입은 하지 않는다. 현재 FastAPI 구조에서 리스크가 작도록
정적 CSS/JS 분리와 각 화면 HTML 정리만 수행한다.

## 접근성 및 반응형
- 모든 버튼은 40px 이상의 터치 영역을 갖는다.
- `:focus-visible` 스타일을 공통 정의한다.
- 색상만으로 상태를 전달하지 않고 텍스트 배지도 함께 사용한다.
- 모바일 360px 폭에서 네비게이션과 버튼 텍스트가 겹치지 않아야 한다.
- `prefers-reduced-motion`을 존중한다.

## 검증
자동 검증:
- 기존 pytest 전체 실행
- 최소한 다음 테스트가 통과해야 한다:
  - `tests/test_login_bruteforce.py`
  - `tests/test_availability_status.py`
  - `tests/test_landing.py`는 오손 랜딩 비변경 확인용으로 유지

수동/시각 검증:
- 로컬 서버 실행 후 `/admin/login`, `/admin/`, `/availability/admin`, `/photos/admin`, `/dashboard/` 확인
- 모바일 폭 360px, 태블릿 768px, 데스크톱 1280px에서 레이아웃 확인
- 라이트/다크 테마 전환 확인
- 예약 추가, 상태 변경, 사진 앨범 생성, 대화 모달 열기 확인

## 비목표
- React/Vue 등 SPA 전환
- 새로운 데이터 모델 추가
- 오손 랜딩 리디자인
- 차트 라이브러리 교체
- 예약 기능의 정책 변경

## 성공 기준
- 관리자 네 화면이 하나의 제품처럼 보인다.
- 홈에서 오늘 운영 상태와 처리할 일을 10초 안에 파악할 수 있다.
- 예약 화면에서 날짜 변경, 잔여석 확인, 예약 추가, 입금대기 확정이 한 화면 흐름으로 이어진다.
- 모바일에서 주요 작업 버튼과 텍스트가 겹치지 않는다.
- 공통 CSS 분리로 색상/버튼/네비게이션 수정 지점이 줄어든다.
